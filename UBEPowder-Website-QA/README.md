# Astoria Philippine Ube Powder Website – QA Case Study

## Project Overview

Independent manual QA testing of the Astoria Philippine Ube Powder e-commerce website.

The purpose of this project was to evaluate the website's functionality, usability, mobile responsiveness and performance, identifying and documenting defects through structured testing.

## Project Details

- **Website:** https://ubepowder.com.ph/
- **Testing period:** November 9–23, 2026
- **Testing type:** Manual exploratory and functional testing
- **Test environments:** Windows desktop and iPhone 15
- **Browser:** Google Chrome
- **Defect tracking:** Jira
- **Performance testing:** Google Lighthouse

## Testing Scope

- Navigation and links
- Shop listings and product pages
- Shopping cart functionality
- Search functionality
- Cookie preferences
- Language switching
- Mobile responsiveness
- Performance, accessibility, best practices and SEO audits

## Key Results

- Identified and documented 13 issues in Jira.
- Conducted manual testing across desktop and mobile devices.
- Performed 20 Google Lighthouse audits across four page and device combinations.
- Created structured test documentation and a final QA summary.
- Conducted an additional AI-assisted review using Codex and manually reproduced relevant findings before documenting them.
